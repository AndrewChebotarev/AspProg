# Почему L(T) работает для N=1, но не работает для N=2 (и как это исправить)

## 1. Математическая основа

### 1.1 Модель сигнала

Наблюдаемый сигнал (формула 4):
```
ξ(t) = s(t) + n(t)
```

где отклик канала (формула 3):
```
s(t) = Σᵐ Σₖ Aₖ · aₘ · cos(ωₘ·(t - τₖ) - φₘ - ψₖ)
```

### 1.2 Достаточные статистики (формулы 87-88)

```
xₘ = (2/N₀) · ∫ ξ(t) · cos(ωₘ·t) dt
yₘ = (2/N₀) · ∫ ξ(t) · sin(ωₘ·t) dt
```

Вектор Z' (формула 96):
```
Z' = [a₁x₁, a₂x₂, ..., aₘxₘ, a₁y₁, a₂y₂, ..., aₘyₘ]  — размер (2M,)
```

### 1.3 Матрицы C, S, H (формулы 92, 95)

```
Cₘₖ = cos(ωₘ·τₖ + φₘ)    — размер (M × N)
Sₘₖ = sin(ωₘ·τₖ + φₘ)    — размер (M × N)

H = [C  -S]               — размер (2M × 2N)
    [S   C]
```

### 1.4 Матрица Q (формулы 80-82)

```
Qcc_ik = Σₘ (2·aₘ²/N₀) · cos(ωₘ·(τᵢ - τₖ))
Qcs_ik = Σₘ (2·aₘ²/N₀) · sin(ωₘ·(τᵢ - τₖ))    — ИСПРАВЛЕННЫЙ ЗНАК

Q = [Qcc  Qcs]            — размер (2N × 2N)
    [Qcsᵀ Qcc]
```

**Важное свойство** (проверено численно):
```
Hᵀ · H = (N₀/2) · Q       — выполняется точно при исправленном знаке Qcs
```

### 1.5 Логарифм ФОП (формула 100)

```
L(T) = 0.5 · Z' · H · Q⁻¹ · Hᵀ · Z'ᵀ
```

## 2. Случай N=1 (M=2) — РАБОТАЕТ

### Размерности

| Объект | Размер |
|--------|--------|
| Z' | (4,) |
| H | 4 × 2 |
| Q | 2 × 2 |
| Q⁻¹ | 2 × 2 |
| H · Q⁻¹ · Hᵀ | 4 × 4 |

### Почему L(T) зависит от τ

При N=1 матрица H имеет размер **4×2** (прямоугольная, M > N). Выражение:

```
H · Q⁻¹ · Hᵀ
```

даёт матрицу **4×4**, которая **НЕ** равна (2/N₀)·I. Она зависит от τ через C(τ) и S(τ). Поэтому:

```
L(T) = 0.5 · Z' · [H(τ) · Q⁻¹(τ) · Hᵀ(τ)] · Z'ᵀ
```

зависит от τ, и максимум достигается при истинном τ.

### Интуиция

При N=1 у нас M=2 частоты, но всего 1 неизвестная задержка. Система **переопределена** (4 уравнения, 1 неизвестная τ). Избыточность измерений позволяет L(T) иметь выраженный максимум.

## 3. Случай N=2, M=2 — НЕ РАБОТАЕТ

### Размерности

| Объект | Размер |
|--------|--------|
| Z' | (4,) |
| H | 4 × 4 |
| Q | 4 × 4 |
| Q⁻¹ | 4 × 4 |
| H · Q⁻¹ · Hᵀ | 4 × 4 |

### Ключевое наблюдение

При N=2, M=2 матрица H имеет размер **4×4** (квадратная). Используя свойство `Hᵀ·H = (N₀/2)·Q`, получаем:

```
H · Q⁻¹ · Hᵀ = H · [(2/N₀) · (Hᵀ·H)⁻¹] · Hᵀ
             = (2/N₀) · H · (Hᵀ·H)⁻¹ · Hᵀ
             = (2/N₀) · I₄ₓ₄
```

**Доказательство**: Для квадратной обратимой матрицы H:
```
H · (Hᵀ·H)⁻¹ · Hᵀ = H · H⁻¹ · (Hᵀ)⁻¹ · Hᵀ = I
```

### Следствие

```
L(T) = 0.5 · Z' · [(2/N₀) · I] · Z'ᵀ = (1/N₀) · Z' · Z'ᵀ = const
```

**L(T) не зависит от τ!** Это объясняет, почему:
1. С оригинальной Q (неправильный знак): L(T) даёт ложный максимум из-за численной нестабильности (Q почти сингулярна при τ₁≈τ₂)
2. С исправленной Q: L(T) = const для всех τ

### Интуиция

При N=2, M=2 у нас 4 достаточные статистики (x₁, y₁, x₂, y₂) и 4 неизвестных параметра A_cs (A₁cosψ₁, A₁sinψ₁, A₂cosψ₂, A₂sinψ₂). Система **точно определена**. Для любых τ можно подобрать A_cs так, чтобы восстановленный сигнал идеально совпадал с наблюдениями. L(T) не может различить разные τ.

### Демонстрация

```python
# При N=2, M=2: H @ Q^{-1} @ H^T = (2/N0) * I
H = compute_matrix_H(C, S)  # 4x4
Q = compute_matrix_Q(omega_m, a_m, tau, N0)  # 4x4
result = H @ np.linalg.inv(Q) @ H.T
print(np.max(np.abs(result - (2/N0) * np.eye(4))))  # ~1e-15
```

## 4. Случай N=2, M=3 — РАБОТАЕТ

### Размерности

| Объект | Размер |
|--------|--------|
| Z' | (6,) |
| H | 6 × 4 |
| Q | 4 × 4 |
| Q⁻¹ | 4 × 4 |
| H · Q⁻¹ · Hᵀ | 6 × 6 |

### Почему L(T) снова зависит от τ

При N=2, M=3 матрица H имеет размер **6×4** (прямоугольная, M > N). Свойство `Hᵀ·H = (N₀/2)·Q` выполняется, но:

```
H · Q⁻¹ · Hᵀ = H · [(2/N₀) · (Hᵀ·H)⁻¹] · Hᵀ
             = (2/N₀) · H · (Hᵀ·H)⁻¹ · Hᵀ
```

Теперь H — прямоугольная 6×4. Матрица `H · (Hᵀ·H)⁻¹ · Hᵀ` — это **проектор** на пространство столбцов H размером 6×6, который **НЕ** равен I. Он зависит от τ через H(τ).

Поэтому:
```
L(T) = 0.5 · Z' · [H(τ) · Q⁻¹(τ) · Hᵀ(τ)] · Z'ᵀ
```

зависит от τ, и максимум достигается при истинных τ₁, τ₂.

### Интуиция

При N=2, M=3 у нас 6 достаточных статистик (x₁, y₁, x₂, y₂, x₃, y₃) и 4 неизвестных параметра A_cs. Система **переопределена** (6 уравнений, 4 неизвестных). Избыточность измерений позволяет L(T) иметь выраженный максимум.

---

## 5. Общее правило

| Условие | Статус | Причина |
|---------|--------|---------|
| M > N | ✅ Работает | H прямоугольная (2M × 2N), L(T) зависит от τ |
| M = N | ❌ Не работает | H квадратная (2N × 2N), L(T) = const |
| M < N | ❌ Не работает | Система недоопределена, Q сингулярна |

**Для оценки N лучей необходимо M ≥ N+1 частот.**

## 7. Резюме

1. **N=1, M=2**: H размер 4×2 (прямоугольная) → L(T) зависит от τ → **работает**
2. **N=2, M=2**: H размер 4×4 (квадратная) → H·Q⁻¹·Hᵀ = (2/N₀)·I → L(T) = const → **НЕ работает**
3. **N=2, M=3**: H размер 6×4 (прямоугольная) → L(T) зависит от τ → **работает**

**Решение**: Переход от M=2 к M=3 частотам восстанавливает работоспособность формулы (100) для N=2.
